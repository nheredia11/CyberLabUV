Catalogo inicial de escenarios

Pensado para demostrarle a tu tutor que ya empezaste la fase de configuracion del entorno y que el proyecto avanza hacia un prototipo con recorrido pedagogico, evidencia tecnica e interfaces basicas.

Arquitectura de esta iteracion

Capa de interfaz

Landing principal del prototipo y laboratorio web de autenticacion controlada para mostrar progreso visual y facilitar validacion con docentes y estudiantes.

Capa de orquestacion

Scripts dedicados por escenario, Compose por laboratorio y variables centralizadas para que el proyecto sea mas mantenible y demostrable.

Capa de escenarios

Reconocimiento, autenticacion HTTP y base web OWASP, cada uno con su propia red o despliegue y con margen claro para crecer por iteraciones.

Capa pedagogica

Modulos con teoria, checkpoints y encuesta para unir el ejercicio tecnico con evidencia de aprendizaje y material de sustentacion.

Ruta recomendada de avance

Semana tecnica 1

Probar catalogo e iniciar S01

Levanta el escenario de reconocimiento, toma capturas y registra la primera evidencia de activos visibles dentro de la red aislada.

Semana tecnica 2

Validar S02 con tu tutor

Usa la interfaz del laboratorio HTTP para mostrar debilidades observables y cerrar con mitigaciones propuestas.

Siguiente iteracion
