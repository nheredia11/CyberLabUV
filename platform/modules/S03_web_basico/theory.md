# S03 - Aplicacion web vulnerable para practicas OWASP

## Proposito
Este modulo deja lista la base para integrar un laboratorio web alineado con OWASP Top 10. En esta iteracion se configura la plantilla de despliegue y la interfaz de catalogo dentro del prototipo.

## Enfoque recomendado
- concentrar la validacion en un subconjunto de riesgos web;
- documentar hallazgos y mitigaciones;
- medir facilidad de uso y claridad del recorrido del estudiante.

## Temas sugeridos para iteraciones posteriores
- validacion de entradas;
- gestion de sesiones;
- monitoreo y evidencias;
- mensajes de error y exposicion de informacion.
