# Roadmap corto de interfaces y escenarios

## Ya configurado en esta iteracion
- interfaz principal del prototipo;
- catalogo de escenarios con estados;
- escenario de reconocimiento con red aislada y varios servicios;
- laboratorio HTTP propio para estudiar autenticacion debil;
- plantilla base para escenario web OWASP.

## Siguiente iteracion recomendada
1. persistir resultados por estudiante;
2. agregar vista de instructor;
3. consolidar medicion de tiempos y checkpoints;
4. convertir la landing estatica en una interfaz ligera con backend propio.

## Criterios para priorizar
- que el cambio fortalezca la demostracion ante tutor;
- que sea reproducible en Linux;
- que deje evidencia tecnica y pedagogica;
- que no salga del alcance de una tesis de pregrado.
